# 三、三极管的工作与基极电阻选值
- 三极管在正常工作下，存在三种状态：截止，放大，饱和。三种状态随着Ib的大小而变化，随着Ib从0开始变大，依次进入截止，放大，饱和区。只有三极管工作在饱和区时，才会有三极管的ce导通。
- 对于基极电阻的选值，Vce，Ib，Ic都需要考虑，当Ib*β大于Ic时才会饱和导通。因此，选型流程：（1）IcMAX，负载能过的最大电流（2）Ib大于IcMAX/β（3）R=（Vce-Vbc）/Ib。
# 四、PNP（P管）与NPN（N管）的区别
1. 当三极管用作开关时，通常下，N管控制GND，P管控制VCC（相对于负载）
以NPN为例，在Vb-Ve>0.7V时，三极管才会导通如果负载是接在NPN下的，假定电路导通，则Vb+0.7V=V负载，对于基极要求输出的电压过大，不适用与控制电路。
![355](https://i-blog.csdnimg.cn/direct/82677f6fa2ac40238b635d74b0ed4cc5.png)
2. 二者的工作逻辑完全相反。对于NPN，b高电平导通；对于PNP，b低电平导通。
# 五、三极管的输出反向功能
![449](https://i-blog.csdnimg.cn/direct/4fa4de500c39406fa4f7aa8542e3163c.png)
- 当IN=1时，三极管导通，OUT被直接拉到GND，即OUT=0；当IN=0，三极管截止，OUT电压近似VCC，即OUT=1。在这个电路中OUT的值与IN的值是相反的。
# 六、三极管的基极上拉（N）下拉（P）电阻
![499](https://i-blog.csdnimg.cn/direct/0a90d02bd5e04c3eb6a9e50174bd08a0.png)
- 对于b极，正常情况下只有在高电平下才能导通三极管，但是如果有一些外部噪声（比如人体工频干扰）存在，可能会在基极产生高电平，影响正常工作；加入R3，可以给这个电流一个放电的回路，避免电流影响三极管。
- R3的选值需要保证在噪声下无法形成0.7V的电压。
# 七、三极管的最大耐压
- 在ce的压差达到一定程度之后，会有电流流过，如果此时断开电压，则没有任何问题。如果不撤电压，电流会逐渐变大，直到烧坏三极管。
- 对于反向电压的限制，一般是Vbe<Vce<Vcb。
