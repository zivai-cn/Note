由于二极管存在导通压降以及反向截止的特性，假定通入交流电压，反向电压全部被截止，正向电压的最大值会距离峰值会有0.7v的压降。

# 四、二极管的钳位功能
![496](https://i-blog.csdnimg.cn/direct/bd483c8410aa487f94ff4d03df11f54c.png)
原理：在电路导通之后，二极管的压降近似稳定恒定，可以对信号线进行钳位。
在上电路图中，D1将R2两端的电压钳制在了0.7v。
使用条件：R2与R1的分压中，R2的分压要大于二极管的导通压降。
用途：通常用在信号线上作为保护电路。信号线通常只有小电流小电压，二极管可以防止有大电压流入。
 ![](https://i-blog.csdnimg.cn/direct/eb9ae3781b5b4c58890d54e29ce68071.png)
D2将电压控制在-0.7v之上，D1将电压控制在3.3+0.7V之下。
# 五、二极管控制电路中的电流方向
对于只允许电路中电流单向流过的情况，用二极管做保护。
![](https://i-blog.csdnimg.cn/direct/3ff290e9b34a4ebc8e56957c8d803c1e.png)
应用：
电源接口的防呆设计，防止正负极接反而烧毁电路。
通常情况下，二极管放在VCC入口而不是GND，因为二极管的导通压降将会使GND！=0V，影响系统的工作。
# 六、二极管的使用注意事项
在二极管正向工作时，压降恒定，此时需要注意流过的最大电流，防止二极管过热烧毁。
在反向工作时，则需要注意反向的最大耐压，超过最大耐压，将会击穿二极管，二极管处于导通状态。

# 八、TVS管（瞬间抑制二极管）
TVS平时处于反向截止状态，一旦有异常的浪涌电压时，TVS管导通，将两端的电压钳制在一个安全值，放大电流通过TVS。TVS的相应速度极高，可以通过上千伏的电压。通常用于电源入口的后级电路保护以及高频信号的保护。
# 九、肖特基二极管
对于二极管，反向截止其实是有一段很小的时间是导通的，之后会到完全截止。在高频电路中，这个导通时间的影响很大，因此需要使用肖特基二极管。
肖特基二极管的相应时间极短，但是漏电流大，同时耐压低。
