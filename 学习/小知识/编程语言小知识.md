## 消除参数未使用警告
在回调函数中，例如信号处理、定时器回调、线程入口，经常会固定回调原型，结构上要求必须有参数。如果在实际的函数处理中没有用到，放任不管，编译的时候会有参数未使用警告。
解决方案：void强制转换。
```c
void test(int a, int b) { (void)a; (void)b; }
```
## memset函数
函数结构：memset(起始地址, 填充值, 字节长度)
作用：清空指定栈上内存。
```c
实例：
memset(handle, 0, sizeof(Button));
Button为链表结构体，handle作为指针指向首地址，memset将会把整个Button结构体内存全部清零。
```
## 程序入口参数
```c
int main(int argc, char* argv[])
```
argc是参数数量，argv是字符串数组。
当命令行（串口）操作程序时，运行的结果为：argv[0]默认就是文件名称。例如如果文件名称为demo，命令行中执行以下操作，程序结果就是argv[0]=demo，argv[1]=''-v''
```c
./demo -v
```
## 字符串比较函数strcmp
```c
#include <string.h>
```
用法：如果两个字符串相同，返回0，否则返回非0。
```c
if(strcmp(a, b) == 0)
{
    // 两个字符串相同
}

strcmp("abc","bcd")
```
为什么不用等于？字符串本质是内存空间，直接将两个字符串判断是否等于，实际上比较的是两个字符串的地址。
