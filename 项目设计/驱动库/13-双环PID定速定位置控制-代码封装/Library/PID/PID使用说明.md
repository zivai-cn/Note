# PID 控制库使用说明

位置式 PID 控制库，位于 `Library/PID/`（`PID.h` + `PID.c`）。与芯片无关、不依赖 `math.h`，可在 STM32F103（Keil MDK, AC5, C99）上直接使用，也可整体移植到其它平台。

库在基础 PID 之上提供 **积分限幅、积分分离、变速积分、微分先行、不完全微分、输出偏移、输入死区** 七种优化策略，通过 `PID_USE_*` 功能开关按需启用，默认配置（仅积分限幅开启）与基础版控制效果一致。

---

## 一、快速开始

```c
#include "PID.h"

/* 1. 定义 PID 结构体，用指定初始化列表设置增益与输出限幅 */
PID_t Motor = {
	.Kp     = 0.3f,
	.Ki     = 0.3f,
	.Kd     = 0.0f,
	.OutMax =  100.0f,
	.OutMin = -100.0f,
};

void PID_Config(void)
{
	PID_Init(&Motor);				/* 2. 初始化：清零内部状态（首次使用前必须调用） */

	/* 3.（可选）按需启用优化功能并设置参数，见第五节 */
	PID_SetSepBand(&Motor, 10.0f);	/* 例：积分分离阈值 */
}

void PID_Cycle(void)				/* 4. 周期性调用（如定时器中断，周期固定） */
{
	Motor.Actual = GetFeedback();	/* 先写入本次实际值（反馈） */
	PID_Update(&Motor);				/* 再调用 PID 计算 */
	SetActuator(Motor.Out);			/* 输出读取 Motor.Out */
}
```

要点：

- **每个控制周期**：先填 `Actual`，再调 `PID_Update`，输出用 `Out`；目标值写 `Target` 或调 `PID_SetTarget`。
- **内部状态**（`Error0 / Error1 / ErrorInt / Actual1 / DerivFilt / First`）由库管理，请通过 `PID_Init` / `PID_Reset` 操作，**不要直接读写**。
- 新增功能字段在指定初始化列表中默认置 0，因此**现有代码无需修改**。

## 二、API 接口

| 函数 | 说明 |
|---|---|
| `PID_Init(p)` | 初始化，清零内部状态（增益与限幅保留） |
| `PID_Reset(p)` | 复位，清除误差与积分历史（目标值与增益保留） |
| `PID_Update(p)` | PID 计算并更新结构体 |
| `PID_SetTarget(p, Target)` | 设置目标值 |
| `PID_SetKp(p, Kp)` | 设置比例系数 |
| `PID_SetKi(p, Ki)` | 设置积分系数 |
| `PID_SetKd(p, Kd)` | 设置微分系数 |
| `PID_SetSepBand(p, SepBand)` | 设置积分分离阈值 |
| `PID_SetVarIntegral(p, Start, End)` | 设置变速积分误差范围 |
| `PID_SetDerivAlpha(p, Alpha)` | 设置不完全微分低通系数（0~1） |
| `PID_SetOutOffset(p, Offset)` | 设置输出偏移 |
| `PID_SetDeadband(p, Deadband)` | 设置输入死区 |

数据类型宏 `PID_F`：默认 `float`，可按需整体改为 `int32_t` / `double`（位于 `PID.h`，`#ifndef` 保护）。

## 三、功能开关总览

| 功能 | 开关宏（默认值） | 参数字段 | 设置函数 |
|---|---|---|---|
| 积分限幅 | `PID_USE_INT_LIMIT`（**1，默认开**） | 无（由 OutMax/OutMin 自动推导） | — |
| 积分分离 | `PID_USE_INT_SEPARATION`（0） | `SepBand` | `PID_SetSepBand` |
| 变速积分 | `PID_USE_VAR_INTEGRAL`（0） | `VarIntStart` / `VarIntEnd` | `PID_SetVarIntegral` |
| 微分先行 | `PID_USE_DERIVATIVE_FIRST`（0） | 无 | — |
| 不完全微分 | `PID_USE_INCOMPLETE_DERIV`（0） | `DerivAlpha` | `PID_SetDerivAlpha` |
| 输出偏移 | `PID_USE_OUTPUT_OFFSET`（0） | `OutOffset` | `PID_SetOutOffset` |
| 输入死区 | `PID_USE_DEADBAND`（0） | `Deadband` | `PID_SetDeadband` |

- **开关宏**在 `PID.c` 顶部定义（`#ifndef` 保护，可在 Keil 编译器命令行用 `-D PID_USE_XXX=1` 覆盖）。
- **零参数安全**：功能开启后，若对应参数字段为 0，则功能自动无效，行为与基础版一致。
- **默认配置**：仅积分限幅开启，其余关闭，控制效果与基础版一致。

## 四、PID 计算流程

`PID_Update` 按以下顺序执行（`#if` 未启用的步骤自动跳过）：

1. 更新误差：`Error1 = Error0`，`Error0 = Target - Actual`
2. **输入死区**：死区内误差视为 0，微分同步归零
3. 计算有效积分系数 `kiEff`（积分分离 / 变速积分）
4. **误差积分累加 + 积分限幅**（冻结 / 清零语义见注意事项）
5. 微分项计算（微分先行 / 不完全微分）
6. 位置式输出：`Out = Kp*Error0 + kiEff*ErrorInt + Kd*deriv`
7. **输出偏移**
8. 输出限幅：`Out` 限幅到 `[OutMin, OutMax]`
9. 保存状态（微分先行时 `Actual1 = Actual`）

## 五、七种优化策略详解

在闭环 PID 控制系统运行过程中，根据传感器采集到的过程测量值 PV、设定值 SP 的变化形态、信号质量、偏差波动特征以及被控对象稳态运行数据状态，针对性选用以下优化策略。

### 5.1 积分限幅（`PID_USE_INT_LIMIT`，默认开启）

**适用场景**

当传感器检测到被控变量长期大幅度偏离设定值，执行机构已经达到全开、全关等物理输出极限，但测量数据依旧无法趋近目标值，持续存在静态偏差时，需要启用积分限幅策略，通过直接约束积分运算的累加上下限值，阻止积分项无限堆积引发积分饱和，避免后续测量值回归设定点时积分集中释放造成严重超调。

**实现方式**：把误差积分 `ErrorInt` 限幅到 `[OutMin/Ki, OutMax/Ki]`（Ki<0 时上下限对调），保证积分项 `Ki*ErrorInt` 不超出执行机构物理输出范围。限幅值由 OutMax / OutMin / Ki 自动推导，**无需额外参数**。

**启用方法**：默认已开启，保持默认即可。

---

### 5.2 积分分离（`PID_USE_INT_SEPARATION`）

**适用场景**

当操作人员或上位程序对设定值 SP 进行阶跃式大幅修改，传感器采集的测量值 PV 与设定值之间形成较大的瞬时偏差，被控参数需要长时间爬坡才能到达目标数值，系统极易因大偏差下积分快速累积产生超冲震荡时，采用积分分离策略，在偏差超过设定阈值时暂时关闭积分作用仅投入比例微分调节，待测量值靠近设定、偏差缩小后再恢复积分功能消除静差。

**实现方式**：`|误差| > SepBand` 时积分冻结（不累加也不清零，`ErrorInt` 保持不变，输出中积分项归零）；`|误差| ≤ SepBand` 时恢复积分。

**启用方法**

```c
#define PID_USE_INT_SEPARATION 1	/* PID.c 顶部 */
PID_SetSepBand(&Motor, 10.0f);
```

---

### 5.3 变速积分（`PID_USE_VAR_INTEGRAL`）

**适用场景**

若同样存在设定值阶跃变动、偏差由大变小的过程，但传感器测量值在设定点附近波动平缓，对控制器输出连续性要求极高，无法接受积分分离带来的开关式切换冲击，需要积分作用随偏差大小连续平滑增减，则替换为变速积分策略，让积分系数跟随偏差绝对值动态渐变，实现无扰动的静差消除。

**实现方式**：

- `|误差| ≤ VarIntStart`：全速积分（`kiEff = Ki`）
- `VarIntStart < |误差| < VarIntEnd`：线性渐变 `kiEff = Ki * (VarIntEnd - |误差|) / (VarIntEnd - VarIntStart)`
- `|误差| ≥ VarIntEnd`：积分冻结

积分作用随偏差连续平滑增减，无开关切换冲击。

**启用方法**

```c
#define PID_USE_VAR_INTEGRAL 1
PID_SetVarIntegral(&Motor, 5.0f, 20.0f);	/* Start=5, End=20 */
```

---

### 5.4 微分先行（`PID_USE_DERIVATIVE_FIRST`）

**适用场景**

当系统运行过程中设定值 SP 频繁手动或自动跳变，而传感器实际采集的被控过程测量值 PV 本身变化平缓、仅受外界缓慢扰动小幅漂移，为了防止设定值突变直接对误差项微分产生瞬时尖峰输出冲击阀门、加热模块、风机等执行设备，就开启微分先行策略，将微分项仅作用于传感器实测 PV 信号，完全屏蔽设定值跳变带来的微分扰动，同时保留微分对过程干扰的超前抑制效果。

**实现方式**：微分项只对实际值求差：`deriv = Actual - Actual1`，完全屏蔽设定值跳变的微分冲击。`PID_Init` / `PID_Reset` 后首拍自动以当前 `Actual` 同步 `Actual1`，**无冷启动尖峰**。

**启用方法**

```c
#define PID_USE_DERIVATIVE_FIRST 1
```

---

### 5.5 不完全微分（`PID_USE_INCOMPLETE_DERIV`）

**适用场景**

如果传感器传回的原始模拟量数据存在明显高频毛刺、随机抖动、周期性杂波干扰，比如压力变送器受震动跳数、流量瞬时值频繁小幅跳动、液位浮球晃动造成 PV 曲线细碎震荡，常规完全微分算法会放大噪声信号，导致执行机构高频反复动作磨损器件，此时必须使用不完全微分策略，为微分项增加一阶惯性滤波环节，把尖锐的微分脉冲转化为平缓衰减的输出波形，过滤传感器无效噪声。

**实现方式**：对微分项做一阶低通滤波：`DerivFilt += DerivAlpha * (deriv - DerivFilt)`。`DerivAlpha` 为滤波系数（0~1），越大越平滑（惯性越强）；为 0 时滤波关闭。

**启用方法**

```c
#define PID_USE_INCOMPLETE_DERIV 1
PID_SetDerivAlpha(&Motor, 0.3f);
```

---

### 5.6 输出偏移（`PID_USE_OUTPUT_OFFSET`）

**适用场景**

输出偏移策略不直接依据传感器波动数据触发，主要应用在传感器测量值已经稳定锁定在设定值，但 PID 原生运算输出落入执行机构机械死区、最低工作频率区间的工况下，比如调节阀需要固定开度才能开启、水泵需要最低转速防止空转，通过叠加固定输出偏置量让 PID 调节区间落在执行机构有效工作段，保证稳态精度。

**实现方式**：在输出上叠加固定偏置 `Out += OutOffset`（位于输出限幅之前，最终输出仍受 `OutMax` / `OutMin` 约束），把 PID 调节区间搬入执行机构有效工作段。

**启用方法**

```c
#define PID_USE_OUTPUT_OFFSET 1
PID_SetOutOffset(&Motor, 10.0f);
```

---

### 5.7 输入死区（`PID_USE_DEADBAND`）

**适用场景**

当传感器本身存在固有测量误差，或是被控介质存在自然小幅脉动，造成测量值 PV 在设定值周边微小幅度往复来回波动，控制系统反复进行无意义的小幅调节损耗执行部件寿命，且工艺对控制精度允许一定容错范围时，启用输入死区策略，当偏差绝对值小于死区设定值时锁定 PID 输出不再执行调节，只有偏差超出死区范围才启动闭环运算，最大限度减少执行机构频繁启停与小幅动作。

**实现方式**：`|误差| ≤ Deadband` 时误差视为 0（同时清零上次误差，避免退出死区时微分冲击；微分先行开启时同步 `Actual1`，微分项一并归零），PID 输出保持不动作；偏差超出死区才执行闭环运算。

**启用方法**

```c
#define PID_USE_DEADBAND 1
PID_SetDeadband(&Motor, 2.0f);
```

## 六、典型组合方案

整体而言：

- **温度大滞后回路**：常组合 **微分先行 + 积分分离 + 积分限幅 + 不完全微分**
- **压力、流量噪声偏大回路**：搭配 **不完全微分 + 输入死区**
- **阀门非线性严重工况**：叠加 **输出偏移 + 积分限幅 + 输入死区**
- **精密微量平稳控制回路**：使用 **变速积分 + 不完全微分**

依据实时传感器数据形态匹配对应的 PID 优化方案，最终实现系统超调小、设备冲击小、调节平稳可靠的控制目标。

---

## 七、注意事项

1. **零参数安全**：所有优化功能在对应参数字段为 0 时自动无效；默认仅积分限幅开启，控制效果与基础版完全一致，已有调参结果不受影响。
2. **积分冻结 / 清零语义**：`kiEff == 0` 且 `Ki != 0`（积分分离、变速积分生效）时，积分**冻结**（不累加也不清零）；`Ki == 0`（调试时手动清零积分）时，积分**清零**。
3. **微分先行冷启动**：`PID_Init` / `PID_Reset` 后首拍自动以当前实际值初始化，无需调用方预置 `Actual1`。
4. **死区与微分先行**：两者同时启用时，死区内微分先行项自动归零，不产生微分冲击。
5. **输出偏移与限幅**：偏移叠加在输出限幅之前，最终输出仍被 `OutMax` / `OutMin` 截断。
6. **类型宏**：`PID_F` 默认 `float`；若整体改为整数类型，注意 `PID_ABS` 对 `INT32_MIN` 取负会溢出（一般不建议整数 PID_F）。
