# VOFA 串口字符通信模块

这套代码只发送和接收普通字符，不使用 JustFloat 二进制协议，共两个代码文件：

- `VOFA_Serial.c`
- `VOFA_Serial.h`

它直接复用原工程中的 `Serial.c` 和 `Serial.h`。

## 一、加入工程

把 `VOFA_Serial.c` 和 `VOFA_Serial.h` 加入 Keil 工程，并保证可以找到原来的 `Serial.h`。

默认串口配置在 `VOFA_Serial.h`：

```c
#define VOFA_USART           USART1
#define VOFA_BAUDRATE        9600U
#define VOFA_RX_BUFFER_SIZE  100U
```

VOFA+、STM32 和 USB 转串口模块的波特率必须一致。

## 二、初始化

```c
#include "VOFA_Serial.h"

int main(void)
{
    VOFA_Init();

    while (1)
    {
    }
}
```

## 三、STM32 向 VOFA 发送字符

发送普通字符串：

```c
VOFA_SendString("hello vofa\r\n");
```

发送带数字的文本：

```c
VOFA_Printf("heart_rate:%d,spo2:%d\r\n", heart_rate, spo2);
```

如果只是查看文字，可以在 VOFA+ 中使用串口监视功能。

如果需要把字符形式的数字画成曲线，应选择 VOFA+ 的 FireWater 协议，例如：

```c
VOFA_Printf("%d,%d\r\n", heart_rate, spo2);
```

JustFloat 用于发送二进制 `float`，不适合本模块的纯字符数据。

## 四、VOFA 向 STM32 发送字符

在原来的 `USART1_IRQHandler` 中读取一个字节，然后交给模块：

```c
void USART1_IRQHandler(void)
{
    if (USART_GetITStatus(USART1, USART_IT_RXNE) == SET)
    {
        uint8_t rx_data;

        rx_data = (uint8_t)USART_ReceiveData(USART1);
        VOFA_InputByte(rx_data);
        USART_ClearITPendingBit(USART1, USART_IT_RXNE);
    }
}
```

VOFA 发送每条命令时，需要在末尾添加换行符。可以在发送区勾选“发送新行”，或者让发送内容以 `\n` 结束。例如一条命令的实际内容是：

```text
LED_ON
```

在主循环或任务中读取：

```c
#include <string.h>

char command[100];

if (VOFA_HasData())
{
    VOFA_Read(command, sizeof(command));

    if (strcmp(command, "LED_ON") == 0)
    {
        /* 打开 LED */
    }
    else if (strcmp(command, "LED_OFF") == 0)
    {
        /* 关闭 LED */
    }
}
```

注意：整个工程只能保留一个 `USART1_IRQHandler`，不要在不同文件中重复定义。
