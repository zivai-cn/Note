# OLED 菜单库使用说明

一个基于 OLED（SSD1306/SSD1315 等）+ 按键的轻量级菜单库。采用「死循环 + 全屏重绘」方式驱动，结构简单、占用小，适合 STM32 等嵌入式平台。

---

## 1. 文件构成

| 文件 | 说明 |
|------|------|
| `Menu.h` | 菜单库头文件：结构体、接口声明、按键映射宏 |
| `Menu.c` | 菜单库实现：滚动逻辑、光标绘制、按键事件 |
| `Menu_Data.c` | 使用示例：三级菜单（主界面 → 二级 → 三级），可按需改造 |
| `Menu_Data.h` | 示例对外接口：`External_Init()`、`Menu_RunMainMenu()` |

依赖库：`OLED.h` / `OLED.c`（`OLED_Printf`、`OLED_Clear`、`OLED_Update`、`OLED_ReverseArea`）、`Key.h`（`Key_GetNum()`）。

## 2. API 速查

### 2.1 函数

| 函数 | 说明 |
|------|------|
| `void Menu_RunMenu(Option_Class *list, uint16_t itemCount)` | 运行一个菜单（死循环）；`itemCount` = 选项个数 |
| `void Menu_GetKey(void)` | 读取一次按键（每帧循环开头调用一次） |
| `int8_t Menu_RollEvent(void)` | 滚动增量：`+1` 向下 / `-1` 向上 / `0` 无操作 |
| `int8_t Menu_EnterEvent(void)` | 确认键按下返回 `1`，否则返回 `0` |
| `int8_t Menu_BackEvent(void)` | 返回键按下返回 `1`，否则返回 `0` |
| `void External_Init(void)` | （示例）初始化 OLED / 按键 / RTC / 串口等，main 开头调用 |
| `void Menu_RunMainMenu(void)` | （示例）运行主界面（死循环显示时间） |

### 2.2 类型与全局变量

| 名称 | 说明 |
|------|------|
| `Option_Class` | 菜单项：`String` 文本 / `func` 确认回调（`NULL` = 返回） / `Variable` 预留 |
| `MenuProperty Menu_Global` | 全局属性（字体、行高、窗口、字号），在 `Menu.c` 顶部修改 |

### 2.3 按键宏（在 `Menu.h` 中修改）

| 宏 | 默认值 | 作用 |
|----|--------|------|
| `MENU_KEY_UP` | 1 | 光标向上 |
| `MENU_KEY_DOWN` | 2 | 光标向下 |
| `MENU_KEY_ENTER` | 3 | 确认 / 进入 |
| `MENU_KEY_BACK` | 4 | 返回上一级 |

### 2.4 依赖的 OLED / Key 函数

| 函数 | 用途 |
|------|------|
| `OLED_Clear()` | 清屏 |
| `OLED_Printf(x, y, FontSize, fmt, ...)` | 打印文本（菜单项文字） |
| `OLED_ReverseArea(x, y, w, h)` | 反相区域，用作光标高亮 |
| `OLED_Update()` | 刷新屏幕显示 |
| `Key_GetNum()` | 获取按键编号（要求边沿触发） |

### 2.5 最小使用示例

```c
static Option_Class list[] = {
    {"<<<", NULL, NULL},       /* 按确认返回上一级 */
    {"LED ON",  LedOn,  NULL},
    {"LED OFF", LedOff, NULL}
};
Menu_RunMenu(list, 3);         /* 死循环，直到按返回键 */
```

## 3. 快速上手

### 3.1 添加文件到工程

把 `Menu.c`、`Menu_Data.c` 加入编译，头文件搜索路径加入本目录。

### 3.2 main 函数

```c
#include "Menu_Data.h"

int main(void)
{
    External_Init();      // 初始化 OLED、按键、RTC 等
    Menu_RunMainMenu();   // 运行主界面（死循环）
}
```

### 3.3 按键接线（默认）

| 按键 | 编号 | 作用 |
|------|------|------|
| 按键 1 | `1` | 光标向上 |
| 按键 2 | `2` | 光标向下 |
| 按键 3 | `3` | 确认 / 进入 |
| 按键 4 | `4` | 返回上一级 |

编号来自按键库 `Key_GetNum()`。若你的编号不同，只改 `Menu.h` 里的四个宏即可：

```c
#define MENU_KEY_UP       1
#define MENU_KEY_DOWN     2
#define MENU_KEY_ENTER    3
#define MENU_KEY_BACK     4
```

> **要求**：`Key_GetNum()` 必须是**边沿触发**——没有新按键时返回 `0`，每次按下只返回一次编号。

## 4. 核心接口

### 4.1 运行一个菜单

```c
void Menu_RunMenu(Option_Class *list, uint16_t itemCount);
```

- `list`：选项数组，每个元素描述一个菜单项。
- `itemCount`：**选项个数**（数组元素个数，不是最大下标）。
- 这是一个**死循环**，只有两种方式退出：
  1. 选中项 `func` 为 `NULL` 时按下确认键（常见做法是放一项 `"<<<"` 作为「返回」）；
  2. 按下返回键（`MENU_KEY_BACK`）。

### 4.2 选项结构体

```c
typedef struct
{
    char *String;           /* 显示的文本，通常用字符串字面量 */
    void (*func)(void);     /* 确认时执行的函数；NULL = 返回/退出 */
    void *Variable;         /* 预留字段，可关联数据，不用填 NULL */
} Option_Class;
```

### 4.3 按键事件函数

| 函数 | 作用 |
|------|------|
| `Menu_GetKey()` | 读取一次按键（每帧循环开始调用） |
| `Menu_RollEvent()` | 返回滚动增量：`+1` 向下，`-1` 向上，`0` 无 |
| `Menu_EnterEvent()` | 确认键按下返回 `1` |
| `Menu_BackEvent()` | 返回键按下返回 `1` |

> 如果你自己写主界面（不经过 `Menu_RunMenu`），可以直接调用 `Menu_GetKey()` + `Menu_EnterEvent()` 判断按键，见示例 `Menu_RunMainMenu()`。

### 4.4 全局属性

`Menu_Global` 定义在 `Menu.c` 顶部，按实际屏幕/字号修改：

```c
MenuProperty Menu_Global = {
    .Font_Width     = 8,        /* 字体宽度：8 或 6 */
    .Font_Height    = 16,       /* 字体高度 */
    .Line_Height    = 16,       /* 行高：决定一屏显示几行 = Window_H / Line_Height */
    .Window_W       = 128,      /* 窗口宽度 */
    .Window_H       = 64,       /* 窗口高度 */
    .Menu_FontSize  = OLED_8X16 /* 菜单字号，对应 OLED_Printf 的 FontSize */
};
```

> 例：`64 / 16 = 4`，即一屏最多显示 4 行；选项超过 4 个时菜单会自动滚动。

## 5. 如何组织多级菜单

菜单嵌套靠「选项的 `func` 调用另一个 `Menu_RunMenu`」实现。子菜单是**阻塞式**调用，返回后回到上一级继续循环。

```c
/* 三级菜单 */
static void SubMenuC(void)
{
    static Option_Class list[] = {
        {"<<<", NULL, NULL},      /* 按确认返回上一级 */
        {"Op1", Func1, NULL},
        {"Op2", Func2, NULL}
    };
    Menu_RunMenu(list, 3);
}

/* 二级菜单 */
static void SubMenuB(void)
{
    static Option_Class list[] = {
        {"<<<", NULL, NULL},
        {"Enter", SubMenuC, NULL},   /* 确认后进入三级菜单 */
    };
    Menu_RunMenu(list, 2);
}

/* 一级菜单 */
void Menu_RunMainMenu(void)
{
    while (1)
    {
        Menu_GetKey();
        /* ... 这里画主界面 ... */
        OLED_Update();
        if (Menu_EnterEvent())
        {
            SubMenuB();
        }
    }
}
```

**建议**：选项数组加 `static` 修饰，避免占用宝贵的栈空间。

## 6. 工作原理（简明版）

每帧循环：

1. `Menu_GetKey()` 读按键；
2. 判断确认/返回，确认时执行选中项 `func`（`NULL` 则返回）；
3. 判断滚动，更新选中下标并钳位到 `[0, itemCount-1]`；
4. `OLED_Clear()` 全屏重绘：
   - 根据选中项计算显示起点 `show_i`（滚动时保证选中项始终可见）；
   - 逐行打印选项文本；
   - 在选中项处反相高亮一个矩形作为光标；
5. `OLED_Update()` 刷屏。

## 7. 移植注意事项

- **换单片机**：把 `Menu.h` 里的 `stm32f10x.h` 换成对应型号的头文件（提供 `uint8_t` 等类型即可）。
- **改用编码器**：只需改写 `Menu_RollEvent()` 和 `Menu_EnterEvent()` 三个事件函数，核心逻辑不用动。
- **中文菜单项**：光标宽度按 `strlen(文本) × Font_Width` 计算，ASCII 文本正确；中文 UTF-8 每个字占 2~3 字节，宽度会算错。若菜单要显示中文，请自行把宽度改为「按字符数计算」，并确保 `OLED_Printf` 支持中文。
- **按键重复问题**：若从子菜单返回后主界面一闪而过 / 立刻再次进入，多半是 `Key_GetNum()` 是电平触发（按住时一直返回编号）。把它改成边沿触发即可；也可在返回后加短暂延时。
