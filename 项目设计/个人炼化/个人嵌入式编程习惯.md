# 一、全局编程习惯
对于新添加的代码，需要遵循以下规则：
1.  括号采用K&R 风格。
2. 函数命名采用英文功能描述风格，单词中间采用`_`连接。名称可以长，不能为了精简降低可读性。例如：LED_Task_Start();
3. .h文件的内容：声明.c文件中的函数，声明结构体，声明extern变量。
4. 遵循高内聚，低耦合的要求。
5. 函数的参数，操作的外部接口等都需要进行宏定义，方便后续对参数或者接口的修改。宏定义在.c文件中。比如下文中需要操作gpioa13，就先对gpioa13重定义，再进行引用。
6. 如果没有其他特殊要求，新创建的工程需要遵循以下结构：核心代码文件夹——src；src下分出init、platform、hal、modules、其中driversplatform、hal、modules、drivers文件夹，每一级下都有一个src文件夹，一个interface文件夹，前者下存放.c文件，后者存放.h文件。
