# 一、笔记介绍
- git的使用在代码管理中十分普遍，目前已经有需要的图形化操作界面，包括vscode中的git graph插件，软件github desktop等。但是，很多操作并没有在图形化界面中进行展示，因此我们并不能进行一些操作，这将极大的影响我们对于git的使用。

- 在git仓库所在的本地文件夹（和.git同级）下打开命令行。
