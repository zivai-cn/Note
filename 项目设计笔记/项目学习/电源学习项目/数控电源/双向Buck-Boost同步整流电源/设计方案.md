# 基于 STM32 的双向 Buck-Boost DC/DC 平台

## 1. 项目概述

本项目旨在设计一套基于 STM32 数字控制的双向 Buck-Boost DC/DC 平台，实现两个直流端口之间的双向能量传输。

系统采用四开关单电感同步 Buck-Boost 拓扑，通过 STM32 对两端口的电压、电流进行实时采样和控制，实现恒压、恒流等工作模式，并具备良好的动态响应能力和负载稳定性。

本项目定位于：

- 双向 DC/DC 变换平台
    
- 数字电源控制学习平台
    
- 双向能量管理平台
    

而非传统台式电源或电子负载。

---

# 2. 系统架构

系统由两个直流端口组成：

```text
Port A ↔ 双向Buck-Boost ↔ Port B
```

其中：

- Port A 与 Port B 地位对等
    
- 任意时刻仅允许一端作为供电源
    
- STM32 根据当前工作模式控制另一端

# 4. 控制目标

系统控制对象为电压、电流等物理量，而非直接控制 PWM 占空比。

---

## 4.1 恒压模式（CV）

例如：

```text
A端供电
VB = 24V
```

或：

```text
B端供电
VA = 12V
```

---

## 4.2 恒流模式（CC）

例如：

```text
IB = 5A
```

或：

```text
IA = 3A
```

---

## 4.3 限流模式

保护供电端：

```text
IA ≤ IA_MAX
```

或：

```text
IB ≤ IB_MAX
```

# 6. 功率级方案

## 6.1 拓扑选择

采用：

```text
四开关单电感同步Buck-Boost
```

结构如下：

```text
       QH_A
         │
         ●────L────●
         │         │
       QL_A      QH_B
                   │
                 QL_B
```

本质结构：

```text
半桥 + 电感 + 半桥
```

---

## 6.2 方案选择理由

具备：

- 双向传输能力
    
- Buck工作能力
    
- Boost工作能力
    
- 同步整流
    
- 单电感结构
    
- 工业应用成熟
    

适用于：

- 储能系统
    
- 电池管理
    
- 超级电容系统
    
- 双向DC/DC平台

# 7. 采样系统

系统实时采集：

|参数|说明|
|---|---|
|VA|A端电压|
|IA|A端电流|
|VB|B端电压|
|IB|B端电流|

---

STM32根据采样结果计算：

```text
PA = VA × IA
PB = VB × IB
```

用于：

- 功率计算
    
- 效率计算
    
- 能量流向判断
    
- 保护控制
    

---

# 8. 控制架构

推荐采用双环控制结构。

```text
目标电压
    ↓
 电压外环
    ↓
目标电流
    ↓
 电流内环
    ↓
   PWM
```

---

## 电流内环

作用：

- 快速响应
    
- 抑制扰动
    
- 提高动态性能
    

---

## 电压外环

作用：

- 实现稳压
    
- 产生电流参考值
