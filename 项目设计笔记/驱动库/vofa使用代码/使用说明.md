# VOFA 串口字符通信模块

纯字符收发模块，通过 UART 与 VOFA+ 上位机通信，支持 `key:value` 格式解析。依赖 `Serial.c` / `Serial.h`。

**文件**：`VOFA_Serial.c`、`VOFA_Serial.h`、`VOFA_serial_conf.h`

---

## API 速查

| 函数 | 说明 |
|------|------|
| `VOFA_Init()` | 初始化串口 |
| `VOFA_SendString(text)` | 发送 C 字符串 |
| `VOFA_Printf(format, ...)` | 格式化发送 |
| `VOFA_InputByte(byte)` | 中断中喂入一个字节 |
| `VOFA_HasData()` | 是否有完整行就绪，返回 0/1 |
| `VOFA_Read(buf, size)` | 读取一行原始字符串 |
| `VOFA_ParseFloat(key, &val)` | 解析 `key:value` 行，提取浮点数 |

---

## 〇、底层依赖与函数调用关系

本模块不直接操作寄存器，所有收发都委托给底层 `Serial.c` / `Serial.h`，因此移植时必须提供以下两个函数，原型见下表。**移植前请核对底层函数的名称、参数顺序与返回值语义，与下表不一致需先适配底层。**

### 依赖的底层函数原型

| 底层函数 | 功能 | 原型 |
|---------|------|------|
| `Serial_Init` | 初始化串口（GPIO / 外设时钟 / 波特率） | `void Serial_Init(USART_TypeDef *USARTx, uint32_t BaudRate);` |
| `Serial_SendArray` | 发送一段字节数组 | `void Serial_SendArray(USART_TypeDef *USARTx, uint8_t *buffer, uint16_t length);` |

### VOFA 各函数对底层的具体调用

| VOFA 函数 | 底层调用 |
|----------|---------|
| `VOFA_Init()` | `Serial_Init(VOFA_USART, VOFA_BAUDRATE)` |
| `VOFA_SendString(text)` | `Serial_SendArray(VOFA_USART, (uint8_t *)text, (uint16_t)strlen(text))` |
| `VOFA_Printf(format, ...)` | `Serial_SendArray(VOFA_USART, (uint8_t *)buffer, (uint16_t)length)` |

其中：

- **`VOFA_Init()`** —— 只调一次底层 `Serial_Init`，传入配置宏里的 `VOFA_USART` 与 `VOFA_BAUDRATE`，完成外设初始化。若目标项目串口初始化方式不同（如使用 HAL、LL 库或自定义初始化），可替换 `Serial_Init` 为等效初始化，但 `VOFA_USART` 参数仍需传给后续收发函数。
- **`VOFA_SendString(text)`** —— 先把 C 字符串指针强转为 `uint8_t *`（符合底层形参类型），再以 `strlen(text)` 作为长度调用 `Serial_SendArray`。字符 `'a'` 即字节 `0x61`，故字符串可直接逐字节发送。
- **`VOFA_Printf(format, ...)`** —— 先用 `vsnprintf` 把格式化结果写入栈上临时数组 `buffer[VOFA_TX_BUFFER_SIZE]`（128 字节），再以 `Serial_SendArray(VOFA_USART, (uint8_t *)buffer, (uint16_t)length)` 发送；`length` 为实际格式化长度，超长时截断。
- **接收方向不调用底层函数**——`VOFA_InputByte` 由用户在自己工程的 `USART1_IRQHandler` 中断里调用，见下文 4.1；因此底层只需提供发送能力，接收的中断处理在本模块外部完成。

### 移植核对清单

- [ ] 工程中存在 `Serial_Init(USART_TypeDef *USARTx, uint32_t BaudRate)`，且能完成该串口的 GPIO、时钟、波特率配置
- [ ] 工程中存在 `Serial_SendArray(USART_TypeDef *USARTx, uint8_t *buffer, uint16_t length)`，能向 `USARTx` 阻塞或中断发送 `length` 个字节
- [ ] `Serial.h` 头文件搜索路径已加入编译 Include Paths

## 一、加入工程

将四个文件加入工程，确保能找到 `Serial.h`。在 `VOFA_serial_conf.h` 中修改配置以匹配硬件：

```c
#define VOFA_USART           USART1   /* 使用的串口外设         */
#define VOFA_BAUDRATE        9600U    /* 波特率，三方需一致     */
#define VOFA_RX_BUFFER_SIZE  100U     /* 接收缓冲区大小         */
```

## 三、STM32 → VOFA（发送）

### 3.1 发送纯文本

```c
VOFA_SendString("hello vofa\r\n");
```

### 3.2 格式化发送

```c
VOFA_Printf("heart_rate:%d,spo2:%d\r\n", heart_rate, spo2);
```

### 3.3 画曲线（FireWater 协议）

在 VOFA+ 中选择 FireWater 协议，以逗号分隔数据：

```c
VOFA_Printf("%d,%d\r\n", heart_rate, spo2);
```

## 四、VOFA → STM32（接收）

### 4.1 中断接入

在 `USART1_IRQHandler` 中逐字节喂入模块：

```c
void USART1_IRQHandler(void)
{
    if (USART_GetITStatus(USART1, USART_IT_RXNE) == SET)
    {
        uint8_t rx_data = (uint8_t)USART_ReceiveData(USART1);
        VOFA_InputByte(rx_data);
        USART_ClearITPendingBit(USART1, USART_IT_RXNE);
    }
}
```

> 整个工程只能保留一个 `USART1_IRQHandler`。

VOFA+ 发送时需在末尾加换行符：勾选"发送新行"，或让内容以 `\n` 结尾。

### 4.2 方式一：读取原始字符串

```c
char line[100];

if (VOFA_HasData())
{
    VOFA_Read(line, sizeof(line));

    if (strcmp(line, "LED_ON") == 0)
    {
        /* 开灯 */
    }
    else if (strcmp(line, "LED_OFF") == 0)
    {
        /* 关灯 */
    }
}
```

### 4.3 方式二：解析 key:value 格式（推荐）

VOFA+ 发送 `first_Kp:6.39\n`，STM32 端一行代码搞定：

```c
float kp, ki, kd;

VOFA_ParseFloat("first_Kp",  &kp);
VOFA_ParseFloat("first_Ki",  &ki);
VOFA_ParseFloat("first_Kd",  &kd);
```

函数签名：`uint8_t VOFA_ParseFloat(const char *expected_key, float *value);`

- 键名匹配成功 → 返回 `1`，`*value` 写入浮点数
- 键名不匹配或格式错误 → 返回 `0`，自动丢弃该行

综合示例：

```c
while (1)
{
    float val;

    if (VOFA_ParseFloat("first_Kp", &val))
    {
        pid.Kp = val;
        VOFA_Printf("Kp set to %.2f\r\n", val);
    }
    if (VOFA_ParseFloat("target", &val))
    {
        target = val;
        VOFA_Printf("target set to %.2f\r\n", val);
    }
}
```
