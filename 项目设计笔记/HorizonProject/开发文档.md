# 项目的初始化
1. RCC时钟源 设置，高速和低速时钟全部使用外部晶振。
![](assets/开发文档/file-20261014194319492.png)
2. SYS下，Debug模式设置为Serial Wire串行总线调试；由于项目要求使用Freertos，故给系统设置时基源，选择不常用的TIM14。
![](assets/开发文档/file-20261014194401170.png)
3. Freertos软件API标准选择为CMSIS_V2。
![](assets/开发文档/file-20261014195005178.png)
4. 开发环境选择为CMake
![](assets/开发文档/file-20261014195121152.png)
